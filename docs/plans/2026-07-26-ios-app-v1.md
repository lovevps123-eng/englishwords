# EnglishWords iOS App v1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 可在真机日常使用的 EnglishWords v1：登录、每日背词（离线可用）、今日打卡、外刊阅读（点词收藏）、跟读骨架（评分策略待 spike 结论）、设置。听力练习模块等后端计划 3 落地后追加。

**Architecture:** SwiftUI + SwiftData（iOS 17+），MVVM-lite（View + @Observable Store）。网络层薄封装 URLSession，JWT 存 Keychain，401 自动 refresh。单词模块离线优先：启动预取当日队列到 SwiftData，答题结果本地排队、联网批量提交（幂等 client_id）。工程用 XcodeGen 管理（app/project.yml → EnglishWords.xcodeproj）。

**Tech Stack:** SwiftUI, SwiftData, URLSession async/await, AVFoundation(AVSpeechSynthesizer), Speech(SFSpeechRecognizer, 复用 spike), XCTest

## Global Constraints

- 工程目录 `app/`（与 spike/ 平级）；Bundle ID `com.masf.englishwords`；Team `9H47USBKK4`；deploymentTarget iOS 17.0；TARGETED_DEVICE_FAMILY 1
- 后端契约以 spec"API 契约"节为准（`docs/specs/2026-07-25-english-app-refocus-design.md`）：feedback 常量 `know`/`fuzzy`/`unknown`；`/api/vocab/queue?new_limit=&tier=`；results 幂等键=client 生成 UUID；examples key 为 `en/cn/source`
- 服务器 base URL 可在设置页配置，默认 `http://202.182.116.2`（生产未记录域名，经核查 CORS=*、前端同源；Info.plist 需 NSAllowsArbitraryLoads=true 以允许 HTTP，拿到正式域名后收紧）
- 每次任务完成必须：`cd app && xcodegen generate && xcodebuild -project EnglishWords.xcodeproj -scheme EnglishWords -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build` 通过；含逻辑的任务先写 XCTest 再实现（TDD），测试用 `xcodebuild test -destination 'platform=iOS Simulator,name=iPhone 17 Pro'`
- 单元测试 target `EnglishWordsTests` 只测纯逻辑（SRS 队列、同步队列、词对齐、DTO 解码），不做 UI 测试
- 所有用户可见文案中文；代码注释只写非显而易见的约束

### Task 2: 网络层 + JWT 认证 + 登录页

**Files:**
- Create: `app/Sources/Core/APIClient.swift`、`app/Sources/Core/KeychainStore.swift`、`app/Sources/Core/DTO.swift`、`app/Sources/Features/Auth/LoginView.swift`、`app/Sources/Features/Auth/AuthStore.swift`
- Test: `app/Tests/DTOTests.swift`

**Interfaces:**
- Produces: `APIClient.shared.request(_ path:, method:, body:) async throws -> Data` + `get<T: Decodable>/post<T>` 泛型封装；自动附 `Authorization: Bearer`；401 时用 refresh token 调 `/api/auth/refresh` 重试一次，仍失败则登出回登录页
- `KeychainStore`: `saveTokens(access:refresh:)/loadTokens()/clear()`
- DTO（与 spec API 契约逐字段对应，Decodable）：`WordPayload{id,word,phonetic,definitions:[Definition],examples:[Example],stage}`、`Example{en,cn,source}`、`QueueResponse{new,review}`、`StudyStats{learning,mastered,due_today,days_active,streak}`；CodingKeys 处理 snake_case
- 登录页：手机号+密码 → `/api/auth/login`（登录逻辑与网页版共用后端；注册引导文案提示"请先在网页版注册"，v1 不做注册流程）
- TDD：DTOTests 用 spec 里的 JSON 样例断言解码正确（含 due_today 等 snake_case 字段）
- commit `feat(app): 网络层/JWT/登录`

### Task 3: 单词模块核心逻辑（离线队列 + 同步）

**Files:**
- Create: `app/Sources/Features/Vocab/VocabModels.swift`（SwiftData @Model: `CachedWord`、`PendingResult{clientId,wordId,feedback,createdAt}`）
- Create: `app/Sources/Features/Vocab/VocabStore.swift`
- Test: `app/Tests/VocabStoreTests.swift`

**Interfaces:**
- Produces: `VocabStore`（@Observable）：
  - `refreshQueue(tier:newLimit:) async` — 拉 `/api/vocab/queue` 覆盖写入 CachedWord（区分 new/review 分组字段 group）
  - `submit(feedback: String, for word: CachedWord)` — 本地生成 UUID clientId 入 PendingResult 并把词标记已答；纯本地，不等网络
  - `sync() async` — 把 PendingResult 批量 POST `/api/vocab/results`，成功后删除已提交行（幂等键保证重发安全）；失败静默保留
  - `todayProgress: (done: Int, total: Int)`
- TDD（in-memory ModelContainer）：①submit 生成 pending 行且 clientId 唯一 ②sync 成功清空 pending、失败保留 ③refreshQueue 覆盖旧缓存不重复
- commit `feat(app): 单词离线队列与幂等同步`

### Task 4: 背词卡片 UI

**Files:**
- Create: `app/Sources/Features/Vocab/VocabView.swift`、`WordCardView.swift`

**Interfaces:**
- 卡片流程：显示单词+音标 → 自动 AVSpeechSynthesizer 朗读（en-US，可重播按钮）→ 点击"显示释义"翻面（释义+例句 en/cn，例句可朗读）→ 底部三按钮 认识/模糊/不认识（绿/黄/红）→ 调 `VocabStore.submit(feedback:"know"/"fuzzy"/"unknown")` → 下一张
- 队列完成态：显示"今日完成 🎉 已背 N 词"+ 手动同步按钮；顶部进度条 done/total
- 验收：模拟器 build 通过；朗读在模拟器可出声（AVSpeech 无需权限）
- commit `feat(app): 背词卡片`

### Task 5: 今日页 + 我的页

**Files:**
- Create: `app/Sources/Features/Today/TodayView.swift`、`app/Sources/Features/Settings/SettingsView.swift`、`SettingsStore.swift`

**Interfaces:**
- 今日页：每日固定动作清单（背词 N 词【done/total 实时】、跟读 15 分钟、阅读 1 篇——后两项 v1 为手动勾选打卡，存 SwiftData）+ `/api/vocab/study-stats` 的 streak/learning/mastered 卡片；下拉刷新
- 我的页：难度档 Picker（tier 1 基础/2 拔高，存 UserDefaults，改动后触发 refreshQueue）、每日新词量 Stepper（10-100，默认 50）、服务器地址、登出
- commit `feat(app): 今日打卡页与设置页`
