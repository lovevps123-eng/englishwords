# EnglishWords — 英语学习 iOS App

面向北京高中生的英语学习 App（自用/小范围，TestFlight 分发）。覆盖单词（高考 3500 + 拔高层）、发音跟读、听力练习、外刊阅读。

- 客户端：SwiftUI（iOS 17+），本仓库
- 后端：复用 [senior-platform](../senior-platform/) 的 FastAPI（共用 JWT 账号体系），vocab/listening 新增模块在该仓库实现
- 设计文档：[docs/specs/2026-07-25-english-app-refocus-design.md](docs/specs/2026-07-25-english-app-refocus-design.md)
